# Política de segurança

## Relato responsável

Não publique chaves, tokens, imagens privadas ou detalhes exploráveis em uma issue aberta. Use o recurso **Report a vulnerability** na aba **Security** do GitHub quando ele estiver disponível no repositório.

Inclua uma descrição objetiva, o impacto, os passos mínimos para reproduzir e uma sugestão de correção, se houver.

## Segredos expostos

Se uma chave for publicada, removê-la do código não é suficiente. Revogue a credencial no provedor, gere outra chave e depois limpe o histórico do Git antes de tornar o repositório público.

## Escopo

São relevantes falhas que exponham credenciais, permitam abuso da API, contornem validações de upload ou revelem imagens e respostas de outros usuários.
